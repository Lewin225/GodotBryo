Inventory census output

Generated by native/tools/inventory_census.cpp against all official masters.

inventory_entries.csv contains every NPC_/CONT CNTO entry in authored order.
leveled_entries.csv contains every LVLI LVLO entry in authored order.
summary.txt contains record-owner and referenced-type totals.

The census reports references as authored. It does not infer equipped state or
resolve leveled lists, since both require separate runtime behavior evidence.
