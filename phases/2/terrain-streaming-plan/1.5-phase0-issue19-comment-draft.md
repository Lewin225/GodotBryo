# Issue #19 Phase 0 comment draft — do not post

Phase 0 capability work is complete for Terrain Streaming v1.5's CPU/testable gates.

- The real WastelandNV census remains 16,388 usable LAND cells, 292 touched 256×256 regions, and an 18×18 fixed allocation rectangle (324 layers, 648 MiB raw eight-map storage before mipmaps/driver overhead).
- A repeatable 49-cell Goodsprings cold/warm benchmark now splits LAND lookup, region preparation, LTEX and DDS work, texture-pool insertion, pixel writes, publication, collision refresh, and grass binding. Cold `import_cell()` p50/p95/max is 3.90/28.50/179.95 ms; warm is 3.85/4.40/5.50 ms. Cold texture resolution owns the tail; warm per-pixel writes remain about 3.13 ms p50.
- The Terrain3D spike now preallocates a validated deterministic row-major fixed domain once. A complete region replacement updates all eight existing array layers exactly once, emits zero `region_map_changed`, and therefore does not invoke the signal-connected global collision rebuild. Unknown locations and invalid maps are rejected.
- Shared LAND edge/corner samples now have one explicit rule: choose the usable contributing cell with lowest `(x, y)`, falling through gaps/world edges. That single owner supplies height, VCLR, VNML, texture IDs, and weights. Automated tests cover edges, corners, and fallback.
