# Phase 3: continuous finite-domain fill

Status: implemented and focused headless phase gates passed on 2026-08-26. Graphical/GPU validation remains governed by the Phase 0 limitation and is not claimed here.

## Runtime implementation

`TerrainStreamer` now treats complete 256×256 regions as the authoritative unit. Activation initializes the census-derived fixed rectangle once and seeds exactly the touched LAND regions into an explicit lifecycle: `unseen → queued → preparing → prepared → committed`, with `cancelled` used when a generation is invalidated. Cells remain a diagnostic/readiness view and become resident only when every fixed region containing their samples is committed.

The worker count is `clamp(OS.get_processor_count() - 1, 1, 8)`. Each concurrent stager owns its own `EsmFile` and decoded LAND catalogue. Dispatch computes distance from the current camera cell each time a slot becomes available, so crossing a cell boundary immediately changes subsequent choices. `WorldStreamer` hints promote existing entries without adding duplicates. Every fourth dispatch selects the nearest far/background region while any far work exists; the remaining slots select nearest-first work inside radius 20. Publication remains main-thread-only and defaults to one prepared region per frame.

The queue is finite: WastelandNV seeds 292 touched regions inside the 18×18 allocation, never an unbounded spiral. It continues while the camera is stationary until all 292 regions are committed and queued/preparing/prepared counts are zero. Later camera movement performs no further staging or publication.

Texture identities remain frozen logical slots. Main-thread publication resolves only identities used by the prepared region and installs their render LUT entries before upload. The one shipped LTEX path whose DDS is absent (`Landscape\BurntGround01.dds`) maps explicitly to the texture pool's existing pink missing-asset fallback, preserving a valid logical mapping rather than making finite completion impossible.

Far publication does not rebuild dynamic collision. Collision refresh occurs only when the committed region intersects the bound camera's dynamic-collision area; readiness still performs an explicit collision refresh and waits one physics frame.

Grass now separates catalogue discovery from local coverage. Catalogue activation records LTEX→GRAS relationships without creating emitters. `update_coverage(center, committed_nearby_cells)` creates assets only for newly covered committed cells, binds a new emitter material once, and changes emitting state as a single coverage update. Pause disables processing and every emitter; resume restores only covered emitters.

## Measured gates

Environment: Godot 4.7.1 headless dummy renderer, real `FalloutNV.esm` and shipped BSAs.

- Stationary WastelandNV completion: 16,388 usable LAND cells, 292/292 committed regions, 18×18 fixed allocation, zero queued/preparing/prepared work. Representative end-to-end run: approximately 13 seconds.
- Movement after completion: terrain/publication sample counts remain unchanged; no further decode, staging, or upload occurs.
- Phase 1 object-only baseline on the real 1,257-cell radius-20 workload: construction p95 2.184 ms, maximum 13.594 ms, 1,257 samples.
- The same object workload while Phase 3 terrain fill runs: construction p95 2.259 ms, maximum 14.068 ms, 1,257 samples.
- Change from Phase 1: p95 +3.4%, maximum +3.5%; both remain within the required 10% ceiling.
