# Phase 2: native detached region staging

Status: implemented and headless phase gates passed on 2026-08-26. Graphical/GPU evidence is unavailable in this environment and is not claimed.

## Native catalogue and composition

The separate `native/terrain_streamer` GDExtension now exposes `open_esm(path)`, `index_worldspace(worldspace_form_id)`, and `compose_region(worldspace_form_id, region_location, logical_slots)`. Each stager owns its non-thread-safe `EsmFile` and reusable decoded LAND catalogue. The catalogue follows the standalone census rule exactly: real indexed exterior CELLs only, first LAND child only, usable VHGT payloads only, and malformed records isolated per cell.

`index_worldspace()` returns usable cell/FormID pairs, touched regions, fixed rectangle locations/bounds, and unsigned-ascending LTEX FormIDs. Logical slot zero is reserved; the 80 real WastelandNV identities map deterministically to slots 1–80, and catalogues over 127 identities are rejected.

Each CELL payload prepares its four authored layer lists once at catalogue time, including layer-index ordering and strongest-overlay fallback for a missing BTXT. `compose_region()` then applies the lexicographically lowest usable shared-sample owner and writes eight contiguous 256×256 buffers directly. Height/control use RF; color, ID A/B, weight A/B, and normal use RGBA8. Detached Images are created only after every buffer is complete.

Frozen oracle hashes cover a sparse negative-coordinate world edge/gap, missing VCLR, missing BTXT, and the real six-overlay maximum. Every region inherently exercises cell edges and corners; the owner candidate/fall-through rule also has its focused test. Reversing fixture completion order produces identical eight-map hashes. All 16,388 usable first-LAND WastelandNV payloads contain VNML, so this single-master runtime scope has no real missing-VNML sample. A synthetic 33×33 sloped-height fixture therefore exercises the otherwise unreachable native computed-normal path and compares every output byte against the bridge's exact central-difference formula; this is synthetic fallback evidence, not a claim that such a WastelandNV payload exists.

## Fixed publication and runtime handoff

Terrain3D's fixed-domain API validates bounds/duplicates, sorts row-major `(y,x)`, constructs canonical blank maps, and creates the region map and all eight arrays once. Publication rejects unknown locations and malformed map sets, replaces the allocated region's eight maps, updates its cached height range and exactly eight existing array layers, and does not dirty or emit `region_map_changed`.

`TerrainStreamer` now creates and indexes its native stager on `WorkerThreadPool`, initializes the census-derived 18×18 domain on the main thread, and queues complete regions intersecting the unchanged radius-selected cell set. Workers receive only the ESM path, world FormID, region coordinate, and duplicated logical-slot table. The main thread resolves the payload's used LTEX identities, installs the logical-to-render LUT, publishes once, refreshes dynamic collision on the bound camera, and submits one batched grass observation per region.

Pause and deactivation advance generation before results can publish. Detached work may finish, but stale payloads are rejected without touching Terrain3D; abandoned task resources are reaped after completion. Readiness remains cell-facing for the Phase 1 lifecycle API, but a cell is committed only after every fixed region to which its samples contribute has published.

## Measured gates

Environment matches the Phase 0 baseline: Godot 4.7.1 headless dummy renderer, Ryzen 7 9800X3D, 30 GiB RAM.

- Native WastelandNV index: 16,388 usable cells, 292 touched regions, 18×18 fixed rectangle, 80 LTEX identities; representative run 2,087 ms.
- Complete Goodsprings-area region: 11.56 ms for 72 contributing real cells, or 0.161 ms/cell.
- Stress-run fixed-layer publication: seven samples, p95 1.67 ms, below 16.67 ms.
- Staging plus p95 publication amortizes to approximately 0.184 ms/cell for that region. Against the remeasured warm legacy CPU writes plus publication baseline of 3.65 ms/cell, this is about 19.8× faster (target was at least 2×).

The publication timing excludes lazy texture decode/pool insertion, which is separately visible in the Phase 0 stage timings and can have a cold-cache tail. No GPU-completion time is inferred from the dummy renderer.
